# Рекламне відео: бриф і сценарій

Складено за скілом video-ad-generator (Creative Brief, Hook Formulas, Problem-Agitate-Solve). Генерація: Vivix, модель `vivix-w1`, 15 с, 16:9.

## Creative Brief

| Поле | Значення |
|---|---|
| Продукт | Веб-додаток "Тижневі звіти": тижневий огляд філії за звітами відділів |
| Ціна | Безкоштовно, працює в браузері |
| Аудиторія | Директори та керівники філій навчальних закладів (35-55 років) |
| Головний біль | Щоп'ятниці 5-6 звітів у Word від маркетингу, продажів, МУП, фінансів; немає цілісної картини |
| Поточне рішення | Читати все вручну, зводити в голові або в таблиці |
| Заперечення | "Ще один сервіс, треба платити, навчатися, передавати дані" |
| Ключова вигода | Огляд філії за хвилину: оцінки відділів, тренди, ризики, план дій |
| Підтвердження | Файли не надсилаються нікуди; працює з наявними шаблонами звітів |
| Платформа | YouTube / LinkedIn / презентація для керівників, 16:9, звук увімкнено |
| Довжина | 15 с |
| Тон | Професійний, спокійний, теплий |
| CTA | "Тижневі звіти. Огляд філії за хвилину. Безкоштовно." |

## Структура (Problem-Agitate-Solve)

| Час | Кадр | Голос за кадром |
|---|---|---|
| 0-4 с, хук (POV / проблема) | Втомлена директорка ввечері за столом, роздруківки звітів, на ноутбуці купа відкритих документів | "П'ятниця. Шість звітів від відділів. І жодної ясності." |
| 4-9 с, рішення | Перетягує файли в чистий дашборд: графіки, картки з оцінками, короткий список пріоритетів; камера наїжджає на екран | "Завантажте звіти, і за хвилину бачите оцінки відділів, тренди та ризики." |
| 9-15 с, результат + CTA | Усміхається, закриває ноутбук і йде на коротку нараду з командою | "Тижневі звіти. Огляд філії за хвилину. Безкоштовно." |

Текст на екрані свідомо не генерується моделлю (кирилиця в AI-відео часто спотворюється). Назву і посилання краще додати титром при монтажі.

## Варіанти хуків для A/B тесту (наступні генерації)

1. Питання: "Скільки часу ви витрачаєте на тижневі звіти?"
2. Сміливе твердження: "Шість звітів відділів в одному огляді за хвилину."
3. POV: "Коли в п'ятницю ввечері нарешті зрозуміло, що відбувається у філії."
