# Тижневі звіти: аналіз продуктивності

Веб-додаток на Next.js для Vercel. **Працює безкоштовно, без API-ключа:** усе читання файлів і аналіз відбуваються у браузері.

## Режим "Звіти відділів" (основний)

Перетягніть усі звіти за тиждень (.docx, .xlsx, .txt): маркетинг, продажі, МУП, фінанси, рев'ю директора, особисті звіти.

- **Локальний аналіз за правилами** (`lib/localReview.ts`), налаштований під шаблон звітів "1. Маркетинг / Досягнення / Проблеми / Плани на наступний тиждень":
  - період і філія, розділи відділів, досягнення, проблеми, плани; повтори з рев'ю відкидаються;
  - KPI з тексту: витрати, ліди, кліки, CPC, CTR, ціна ліда й конверсії (Meta/Google, Академія/Школа), контакти, договори, час на лінії по містах, втрати, поновлення, оптимізовані групи, боржники, показники з особистих xlsx-звітів;
  - втрати студентів за причинами (без імен), спільні причини для кількох відділів, ризики, якість даних (різні періоди у звітах, відсутні звіти);
  - оцінка відділу 0-100 за правилами (досягнення, проблеми, серйозні проблеми, наявність показників).
- **Історія тижнів і ML** (`lib/trends.ts`): графік оцінок відділів по тижнях, динаміка кожного KPI, прогноз лінійною регресією (від 3 тижнів), аномалії за стійким z-score (медіана, MAD; від 4 тижнів). Історія зберігається в браузері, є експорт/імпорт JSON.
- **Глибший аналіз у Claude через підписку claude.ai**: кнопка копіює готовий запит (інструкції, JSON-схема, текст звітів), ви вставляєте його в claude.ai, а відповідь вставляєте назад. Огляд замінюється на версію Claude і позначається іконкою.

## Шаблони звітів

На сайті в блоці "Шаблони звітів" можна скачати 5 шаблонів .docx: Маркетинг, Продажі, Навчальна частина (МУП), Фінансовий відділ, Тижневе рев'ю філії. У кожному:

- шапка "Філія / Період / Звіт підготував(ла)";
- таблиця "Показник | Значення | Одиниця" з фіксованими назвами показників: цифри беруться звідти напряму, тож тренди між тижнями сходяться;
- у МУП таблиця "Причина втрати | Кількість | Можна повернути" (без імен);
- блоки "Досягнення / Проблеми / Плани на наступний тиждень"; підказки в [квадратних дужках] ігноруються, якщо їх не замінили.

Шаблони генеруються скриптом `scripts/make-templates.mjs`:

```bash
npm run templates                                   # оновити public/templates
node scripts/make-templates.mjs --example ./example # заповнений приклад для перевірки
```

Щоб додати свій показник, допишіть рядок у відповідну таблицю в скрипті (або прямо в шаблоні .docx).

## Режим "Таблиця метрик"

CSV/Excel у форматі "дата, виконавець, числові метрики, коментар": бал продуктивності 0-100 відносно команди, тренд і прогноз, аномалії, кластери k-means, хто не здав звіт (`lib/ml.ts`). Висновки Claude так само через копіювання запиту.

## Запуск локально

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

Відкрийте http://localhost:3000.

## Деплой на Vercel

Покрокова інструкція для нетехнічного користувача: [ДЕПЛОЙ_НА_VERCEL.md](ДЕПЛОЙ_НА_VERCEL.md). Коротко:

1. Залийте папку в GitHub-репозиторій (або виконайте `npx vercel` у цій папці).
2. На vercel.com: **Add New → Project**, імпортуйте репозиторій, натисніть Deploy. Змінні середовища не потрібні.

## Необов'язково: Claude API

Якщо колись з'явиться оплачений ключ API, додайте на Vercel змінну `ANTHROPIC_API_KEY` (і бажано `APP_PASSWORD`). Тоді поруч із копіюванням запиту з'явиться кнопка "Через API", яка робить те саме автоматично (модель `claude-opus-5-5`, структурований вивід). Без ключа ця кнопка прихована і нічого не коштує.

## Конфіденційність

Файли читаються лише в браузері і на сервер не надсилаються. Текст звітів потрапляє в Claude тільки тоді, коли ви самі копіюєте запит у claude.ai (або натискаєте "Через API"). Звіти МУП містять ПІБ студентів: за потреби приберіть їх перед копіюванням.
